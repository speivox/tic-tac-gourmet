# Variantes de direção visual

Snapshots congelados para comparação. Não são gerados pelo `build.py` — se a direção de
alguma for escolhida, ela volta para `src/`.

- **v1** — serifada (Cormorant Garamond), títulos grandes, fundo preto. Primeira proposta.
- A versão em `/index.html` é a direção atual, inspirada em mafoz.com.br.
